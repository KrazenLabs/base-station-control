# Base Station Control

Control your SteamVR base stations directly from within the Steam Frame (or even automatically)!

Base Station Control adds a base station status icon to the SteamVR bar. Clicking it allows you to see the status of all your base stations, toggle them on and off and you can configure having them automatically turn on or off with the headset or with compatible applications (like VRChat or Resonite). No more need for a separate phone app if you use full body tracking with a Steam Frame :)

## Install

Download `BaseStationControl-Setup-<version>.exe` (Windows) or
`BaseStationControl-Setup-<version>-linux-x64.tar.gz` (Linux) from the
[latest release](https://github.com/KrazenLabs/BaseStationControl/releases/latest) and run it and follow the instructions.
Super easy and only takes 30 seconds.

## Usage

Click the new base station icon in the SteamVR bar to access the controls.

## Updating

Either update from the Community Apps tab provided directly in the headset or just download the latest installer and run it again.

## Uninstall

You can uninstall directly from the Community Apps tab in the headset.
